# Insert Margin Block at Cursor

Inserts a Quarto column-margin block with placeholder text directly at
the cursor.

## Usage

``` r
insert_margin()
```

## Value

None. Inserts text into the active RStudio document.

## Examples

``` r
if (FALSE) { # \dontrun{
if (interactive()) {
  insert_margin()
}
} # }
```
