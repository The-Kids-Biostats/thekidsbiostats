# Handle Output for Unsupported Model Types

Internal function to handle cases where the model type is unsupported.

## Usage

``` r
# Default S3 method
thekids_model_output(model, ...)
```

## Arguments

- model:

  A model object of an unsupported class.

- ...:

  Additional arguments (currently unused).

## Value

Stops execution with an error message indicating the unsupported model
type.
