# Handle Output for Negative Binomial Models

Internal function to handle the output for objects of class `negbin`.

## Usage

``` r
# S3 method for class 'negbin'
thekids_model_output(model, ...)
```

## Arguments

- model:

  A fitted negative binomial model object of class `negbin`.

- ...:

  Additional arguments (currently unused).

## Value

A list of model-specific output.
