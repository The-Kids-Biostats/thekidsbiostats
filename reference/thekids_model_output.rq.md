# Handle Output for Quantile Regression Models

Internal function to handle the output for objects of class `rq`.

## Usage

``` r
# S3 method for class 'rq'
thekids_model_output(model, ...)
```

## Arguments

- model:

  A fitted quantile regression model object of class `rq`.

- ...:

  Additional arguments (currently unused).

## Value

A list of model-specific output.
